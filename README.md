# MemeAlerts Award

Десктопное приложение для Windows, macOS и Linux: награда за баллы канала Twitch начисляет мемкоины саппортеру по введённому нику MemeAlerts. Окно сворачивается в системный трей, сбор продолжает работать в фоне.

Это первая рабочая база, а не проверенный релиз для распространения: реальные авторизованные запросы требуют аккаунтов и токенов. Адаптер MemeAlerts восстановлен по текущему JavaScript сайта; сквозное начисление на живом аккаунте пока не проверено.

## Запуск

Нужен Python 3.11 или новее.

```sh
python -m venv .venv
# Linux / macOS
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -e .
python app.py
```

Linux требует графическую сессию и библиотеки Qt/X11 или Wayland. Трей зависит от окружения рабочего стола (например, GNOME может потребовать расширение AppIndicator). Если трея нет, закрытие окна завершает приложение с выключением награды.

## Интерфейс

- **Сбор наград** — сохранённая награда, курс, действующие ограничения и журнал. Поиск работает по нику, тексту результата и подробностям; фильтр выделяет начисления, возвраты, обработку и операции для ручной проверки. Выберите строку, чтобы увидеть подробности. Журнал показывает последние 200 операций и все более старые операции с неизвестным результатом.
- **Награда** — название, цена, мемкоины и защита от спама. Во время сбора поля заблокированы. Несохранённые изменения отмечены в навигации; их можно сохранить или отменить. Случайная прокрутка над полем без фокуса не меняет цену или лимит.
- **Подключения** — вход в Twitch, токен MemeAlerts, имена подключённых аккаунтов и сохранение токенов. Ручной ввод токена Twitch раскрывается отдельно. Токен MemeAlerts скрыт по умолчанию и снова скрывается при уходе с экрана.

Кнопка включения/остановки сбора доступна с любого экрана. Пока выполняется запрос, повторное нажатие заблокировано. Ошибки видны в нижней панели и не исчезают при фоновом обновлении журнала. В маленьком окне прокручивается содержимое страницы; навигация и управление сбором остаются на месте.

Горячие клавиши: `Ctrl+1` — сбор, `Ctrl+2` — награда, `Ctrl+3` — подключения, `Ctrl+F` — поиск по журналу. Закрытие окна сворачивает приложение в трей; «Завершить работу» выключает награду и завершает приложение.

## Подключение

1. Client ID Twitch `7ezpvpkkgksgf0zvysmb2hc4a03ji4` встроен в приложение (константа `TWITCH_CLIENT_ID` в `memeaward/desktop.py`). Ручной ввод и регистрация приложения пользователем не нужны. Для входа через Device Code приложение Twitch должно иметь тип **Public**. Client Secret не используется.
2. Нажмите «Войти в Twitch через браузер». Подтвердите разрешения `channel:manage:redemptions` и `user:write:chat` аккаунтом владельца канала. После обновления со старой версии войдите заново, чтобы разрешить сообщения в чат. Можно также вставить user access token с обоими разрешениями и тем же Client ID. Аккаунт должен иметь доступ к баллам канала Twitch.
3. Войдите на [MemeAlerts](https://memealerts.com/). В DevTools браузера откройте Application → Local Storage → `https://memealerts.com`, скопируйте значение `accessToken` в поле приложения. Требуется аккаунт стримера. Токен даёт доступ к аккаунту; не публикуйте его.
4. Нажмите «Подключить аккаунты». При желании включите сохранение токенов в системном хранилище ключей. По умолчанию токены находятся только в памяти. Если keyring недоступен, приложение сообщает об этом и не сохраняет секреты в файлы. Автоматического входа при запуске пока нет: сохранённые токены подставляются, подключение подтверждается кнопкой.
5. Укажите название награды, цену в баллах Twitch и фиксированное количество мемкоинов за получение. Нажмите «Создать награду». Она создаётся выключенной с обязательным вводом ника и сохраняется для этого Twitch Client ID и аккаунта. Чтобы изменить награду, остановите сбор, отредактируйте название, цену или количество мемкоинов и нажмите «Сохранить изменения». Затем включите сбор снова. Уже принятые заявки сохраняют прежнее количество мемкоинов; новый курс применяется к новым заявкам.
6. Нажмите «Включить сбор». Зритель должен ввести **точный ник MemeAlerts**. Учитываются только саппортеры подключённого стримера. Если точного однозначного совпадения нет, приложение отменяет награду, возвращает баллы Twitch и отправляет в чат от имени стримера сообщение с упоминанием зрителя: перейти на https://memealerts.com/, стать саппортером канала, а если он уже саппортер — проверить ник и повторить получение награды.

## Ограничения награды

В блоке «Ограничения» доступны:

- **Пауза, сек.** — общая пауза между получениями награды всеми зрителями (до 7 дней).
- **На зрителя / стрим** — сколько раз один Twitch-зритель может получить награду за стрим.
- **На канал / стрим** — сколько раз все зрители вместе могут получить награду за стрим.

Значение 0 отображается как «Без ограничения» и отключает соответствующий лимит. Для существующей награды остановите сбор, задайте значения, нажмите «Сохранить изменения» и включите сбор снова. Можно начать, например, с паузы 60 секунд и лимита 3 получения на зрителя за стрим. По умолчанию ограничения выключены; обновление приложения само их не включает.

Ограничения применяет сам Twitch до принятия заявки. Пауза меньше 60 секунд действует, но не отображается в интерфейсе Twitch. Пределы за стрим относятся к Twitch-аккаунтам, а не к введённым никам MemeAlerts. Лимиты сохраняются вместе с настройками награды; их изменение не меняет сумму уже принятых заявок. См. [поля ограничений Twitch](https://dev.twitch.tv/docs/api/reference/#update-custom-reward).

## Обработка и восстановление

- Очередь `UNFULFILLED` опрашивается раз в 5 секунд с пагинацией. Публичный сервер и входящие подключения не нужны. Настоящие события EventSub можно подключить позднее, не меняя механизм начисления.
- Сообщение о саппортерстве отправляется только после успешного возврата баллов. Результат отправки виден в журнале. Сбой чата не мешает возврату и не останавливает начисления другим зрителям. Если доставка сообщения не подтверждена или приложение завершилось во время отправки, автоматического повтора не будет, чтобы не дублировать сообщения. Ещё не начатые отправки восстанавливаются при следующем включении сбора.
- SQLite хранит ID получения награды, ник, сумму, состояние и результат. Успешное начисление отдельно фиксируется **до** подтверждения Twitch. Если Twitch не ответил после начисления, при следующем запуске сбора повторяется только подтверждение Twitch.
- Если ответ MemeAlerts потерян либо приложение завершилось во время начисления, запись получает статус «Нужна проверка». Сбор блокируется. Проверьте баланс/историю на MemeAlerts, выделите запись и выберите «Коины уже начислены» или «Вернуть баллы Twitch». Автоматический повтор начисления запрещён: у приватного запроса не обнаружен ключ идемпотентности. Однократность между двумя сервисами при сбое нельзя гарантировать без их поддержки; журнал предотвращает слепые повторные переводы.
- При штатной остановке и выходе приложение выключает награду через Twitch. При подключении после перезапуска сохранённая награда также выключается. Уже принятые, но не выполненные заявки остаются в Twitch и обрабатываются при следующем включении сбора.
- Если приложение аварийно завершилось, компьютер выключился или сеть недоступна, гарантированно выключить награду удалённо невозможно. При ошибке выключения интерфейс просит отключить её вручную. Гарантия «доступна только пока работает приложение» потребует отдельного постоянно доступного сервиса; текущая версия обеспечивает это при штатном управлении.
- Токен Twitch проверяется при подключении, старте и раз в час во время сбора. Истёкшие токены требуют повторного входа; автоматическое обновление токенов пока не реализовано. При ошибке сбор останавливается с попыткой выключения награды.
- Одновременно допускается один экземпляр приложения на каталог данных. Не запускайте две копии с разными каталогами для одной награды.

Данные расположены в `QStandardPaths.AppLocalDataLocation`. Для тестовой изоляции можно задать `MEMEAWARD_DATA_DIR`. Не удаляйте журнал при наличии незавершённых операций: он защищает от повторных начислений. Выданные награды нельзя вручную подтверждать или отменять в Twitch параллельно обработке приложением.

## Сборка и релизы

Публичный репозиторий: [Sluicee/memealerts-award](https://github.com/Sluicee/memealerts-award).
Готовые архивы публикуются в [GitHub Releases](https://github.com/Sluicee/memealerts-award/releases).

Процесс повторяет SongBridge: шесть нативных сборок — Windows, Linux и macOS на x64 и ARM64. Windows получает ZIP, Linux и macOS — `tar.gz`. Архивы содержат всю папку приложения или `.app` и краткую инструкцию. Python на компьютере пользователя не нужен. Сборки пока не подписаны.

- Каждый push в `master` и pull request запускают тесты на Windows, Linux и macOS.
- Ручной запуск **Desktop builds and release** собирает все шесть вариантов и сохраняет их как Actions artifacts на 14 дней, без публикации релиза.
- Push тега `v*` запускает тесты, сборку, проверку запуска каждого готового приложения и публикацию GitHub Release. Перед публикацией проверяется полный комплект шести архивов и создаётся `SHA256SUMS.txt`. Публикуется только полный успешно собранный комплект; теги с дефисом отмечаются как prerelease.
- Actions закреплены на конкретных commit SHA. Отдельные GitHub secrets не нужны: для публикации используется штатный `GITHUB_TOKEN`, право записи выдано только задаче публикации.

Для следующего релиза обновите `version` в `pyproject.toml`, закоммитьте изменения и отправьте новый тег:

```sh
git push origin master
git tag -a v0.1.1 -m "MemeAlerts Award v0.1.1"
git push origin v0.1.1
```

Локальная сборка на целевой ОС:

```sh
python -m pip install -e '.[build]'
python packaging/build.py
```

Скрипт проверяет архитектуру, собирает приложение через PyInstaller, запускает его с `--self-test` и создаёт архив в `release/`. Переменная `BUILD_VERSION` задаёт версию в имени архива (по умолчанию `local`), `BUILD_PLATFORM` при необходимости проверяет ожидаемую платформу. Например, `BUILD_VERSION=v0.1.0 python packaging/build.py` в bash.

Проверка готовой сборки без сети и пользовательских данных:

```sh
# Linux; на Windows используйте MemeAlertsAward.exe
./dist/MemeAlertsAward/MemeAlertsAward --self-test
```

Этот режим проверяет Qt, SQLite и открытие всех экранов на временных данных. Он не входит в аккаунты, не открывает браузер и не создаёт настоящие награды. Проверка обычного запуска с треем, авторизацией и реальным начислением остаётся отдельным ручным сценарием.

## Проверки

```sh
python -m unittest discover -s tests -v
```

Тестируются повторная доставка, перезапуск после начисления, потеря ответа, возврат баллов, восстановление после сбоя, точное сопоставление ников, неоднозначность и пагинация. Проверяются редактирование при остановленном сборе, сохранение старого курса для очереди, ошибки сохранения и отправки чата, защита от дублирования сообщений и новые OAuth-разрешения.

## Архитектура и следующие этапы

- `memeaward/api.py` — Twitch и приватные запросы MemeAlerts.
- `memeaward/engine.py` — независимая от Qt обработка наград.
- `memeaward/storage.py` — журнал SQLite.
- `memeaward/desktop.py` — авторизация, команды и фоновый поток. Сетевые операции не блокируют GUI.
- `memeaward/ui.py` — экраны приложения, трей, поиск журнала и оформление.

Дальнейшая работа: обновление токенов и EventSub; подписанные установщики. Серверный запуск 24/7 — отдельный будущий режим поверх ядра, пока не реализован.

## Источники интеграций

- [Twitch: создание наград, очередь и подтверждение](https://dev.twitch.tv/docs/api/reference/#create-custom-rewards). Управлять можно наградой, созданной тем же Twitch-приложением.
- [Twitch: отправка сообщений в чат](https://dev.twitch.tv/docs/api/reference/#send-chat-message). Требуется `user:write:chat`, отправитель — подключённый стример.
- [Twitch: Device Code Grant](https://dev.twitch.tv/docs/authentication/getting-tokens-oauth/#device-code-grant-flow).
- [Twitch: проверка токенов](https://dev.twitch.tv/docs/authentication/validate-tokens/).
- [MemeAlerts](https://memealerts.com/): 24.10.2026 в публичном JS сайта обнаружены `GET /api/user/current`, `POST /api/supporters` (`query`, `streamerId`, `limit`, `skip`) и `POST /api/user/give-bonus` (`userId`, `streamerId`, `value`), авторизация `Bearer accessToken`. Это внутренний контракт сайта, не официальная публичная интеграция; форматы и доступность могут изменяться. Поддержка MemeAlerts и партнёрский API не используются.
